# Amazon Fire TV Omni QLED / Fire TV 4-Series smart TVs (AFTTIFF43, "brandenburg"), Fire OS 7.7.1.7 (Android 9).
# Tested on a 43" Omni QLED (model AMZ_QL43F601A) on build PS7717.6741N.
#
# Base: cleanyourtv's examples/amazon-fire-tv-afttiff43 list (same model and build line), plus the ad,
# telemetry and experiment packages from dumbtv's Fire OS 7.7.1.7 list.
# Everything is DISABLED for user 0, never uninstalled; cleanyourtv's tools/restore.sh with this list undoes it.
#
# Apply:  TV_HOST=<tv ip> ../cleanyourtv/tools/disable.sh debloat.txt     (run from this repo)
# Undo:   TV_HOST=<tv ip> ../cleanyourtv/tools/restore.sh debloat.txt com.amazon.tv.launcher
#
# Never on this list: com.amazon.tv.launcher (also hosts Settings), com.amazon.vizzini (draws an
# undismissable "Unable to Detect Your Remote" window when disabled), com.amazon.firebat (Prime Video),
# com.mediatek.tvinput (HDMI inputs), com.amazon.venezia (Appstore), AirPlay, casting, remote/Bluetooth.
